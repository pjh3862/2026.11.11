## 게시물 · 생산진도율 자동화

① 직무·소속 : (회사명 생략) 계획운영팀

② 현안 : 생산진도율 자동화
 1) 실적 현장 전산입력
 2) 고객사 발주서·납품이력 자동다운로드
 3) 출하 대비 재고현황 자동 산출

③ 보유 데이터 : 제품별 재고현황(수기 → 엑셀), 고객사 발주서(엑셀)

④ 기대 산출물 : 재고 과부족 시 알림, 공정별 근무 투입조정 필요 알림, 공정별 실적 분석

## 강사 답글로 요청한 것 (기획서 10장)

1. 재고현황·발주서 엑셀 견본
2. 현장 실적 기록 방식(수기 양식·전산 화면)
3. 「자동 다운로드」 대상 고객사 시스템(포털 이름, 엑셀 내려받기 여부)
4. 알림 기준값(안전재고, 공정별 시간당 능력)

사내 전산 연동이 어려우면 엑셀 업로드 방식으로 먼저 시작합니다.
